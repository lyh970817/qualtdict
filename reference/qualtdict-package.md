# qualtdict: Variable Dictionaries and Labelled Data for 'Qualtrics' Surveys

Decodes nested 'Qualtrics' <https://www.qualtrics.com/about/> survey
metadata into a readable Variable Dictionary, one row per exported
response column with question, item, level, label and a generated
variable name, and applies it to downloaded responses to produce
labelled, analysis-ready survey data. The package is a metadata and
labelled-export companion to 'qualtRics', which provides access to
'Qualtrics' survey data and metadata via the 'Qualtrics' API
<https://api.qualtrics.com/>.
